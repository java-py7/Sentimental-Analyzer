# 🎥 YouTube Sentiment Analyzer

An AI-powered web application that analyzes YouTube comments and classifies them as **Positive**, **Negative**, or **Neutral**. 
The application analyzes YouTube comments using NLP techniques, generates interactive charts and word clouds, and allows authenticated users to securely save their analysis history.

## ✨ Features

- Analyze comments from any public YouTube video
- AI-powered sentiment analysis
- Interactive charts and word cloud
- Google OAuth login
- Save and view analysis history
- Responsive and modern UI

## 🚀 Installation

```bash
git clone https://github.com/java-py7/Sentimental-Analyzer.git
cd Sentimental-Analyzer
pip install -r requirements.txt
python app.py
```

---

## 🔑 Environment Variables

Create a `.env` file:

```env
GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_client_secret
YOUTUBE_API_KEY=your_api_key
SECRET_KEY=your_secret_key
```
